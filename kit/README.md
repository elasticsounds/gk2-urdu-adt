# Build kit

Everything used to make this Accessible Digital Textbook, kept here as a reference for converting other books.

| Item | What it is |
|---|---|
| `ADT-conversion-prompt.md` | Prompt to paste into a new Claude Code session to convert another PDF. Give this repository as its reference build. |
| `content/p001.json` … `p096.json` | The source of truth for each page: text, pictures, activities, hints, levels, easy-read. Written page by page from the scans, not generated by a script. |
| `tools/SCHEMA.md` | The format of the content files. |
| `tools/build.py` | Turns `content/` into the site's data, cropped pictures, symbols and audio. `--lang=en` builds the English edition, `--sym` fetches missing symbols, `--tts` generates missing audio. |
| `tools/export.py` | Writes the braille (BRF) and text-only HTML downloads for every page and the whole book into `adt/exports/`. Needs liblouis (`brew install liblouis`). |
| `tools/validate.py`, `tools/validate_en.py` | Check the content files. |
| `tools/dewatermark.py` | General watermark remover: `python dewatermark.py book.pdf out_folder`. Learns a repeated grey watermark from all pages and subtracts it. Tested on this book only. |
| `tools/render.py`, `tools/wm_*.py` | The original one-off page rendering and watermark code for this book. |
| `tools/upscale.py` | Upscales cropped pictures through Replicate. `upscale-classify.json` records which model each picture used. |
| `tools/ENGLISH.md` | Brief used for the English translation pass. |
| `tools/compare*.py`, `tools/compare_template.html` | The upscaler comparison pages. |

## Layout the scripts expect

The scripts were run from a working folder laid out like this, with the published site in `adt/`:

```
work/
  adt/        <- this repository's root (index.html, js, css, data, assets)
  content/
  tools/
  qa/         <- caches and review sheets, created as needed
```

To run them, copy `kit/content` and `kit/tools` up beside a checkout of the site named `adt`.

## Requirements

- Python 3 with `pillow`, `pymupdf`, `numpy`, `opencv-python` and `edge-tts`.
- `REPLICATE_API_TOKEN` in the environment for upscaling.
- Optional symbol-library keys in `tools/.keys.json` (`globalsymbols_key`, `opensymbols_secret`). That file is git-ignored; never commit it.

## Things to know

- Voices come from `edge-tts`, an unofficial route to Microsoft's neural voices. For anything beyond a prototype, use Azure Speech.
- ARASAAC symbols are licensed CC BY-NC-SA.
- The scripts were written for this one book and have not been run on another.
