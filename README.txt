واقفیتِ عامہ (General Knowledge) — Class 2 — Accessible Digital Textbook
=======================================================================
Open index.html in any modern browser (works offline, also from a USB stick or a web server).

Each of the 96 book pages has three views:
  Lesson (سبق)        the book's own wording, re-flowed to fit any screen, with read-aloud,
                       interactive activities (Easy / Medium / Hard), feedback and a Helpful hint.
  Easy Read (آسان)    a short symbol-supported scaffold of the page's core idea + one easy activity.
  Original (اصل صفحہ) the watermark-free original page, with a link to that page as a PDF.

Folders
  assets/pages, assets/pdf   clean original pages (image + one PDF per page)
  assets/img                 pictures cropped from the pages
  assets/sym                 easy-read pictograms
  assets/audio               pre-recorded Urdu (Pakistan) narration, one clip per sentence/word
  data                       page content (one file per page)
